浏览网页

这是一个面向受控来源的受限阅读器。起始页保存在应用包内，打开本页不会发出网络请求。

在地址栏输入允许来源的完整 HTTP 或 HTTPS 地址，再按 Enter。地址不会发送给搜索服务。

开始阅读

  • Ctrl+L 输入地址，Alt+← / → 前后导航。
  • Ctrl+F 查找；拖选文字后 Ctrl+C 复制。
  • Shift+滚轮横向滚动；Ctrl+加号 / 减号 / 0 调整页面缩放。

点击工具栏的“?”查看包内帮助。遇到不支持的内容时，页面会显示标记，状态区会报告受限呈现。

允许来源记录在包内 origins.txt，管理员可修改源码资源后重新构建应用包。每个实例使用独立的网络任务、历史、文档和图片。
