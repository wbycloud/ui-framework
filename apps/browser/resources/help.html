受限浏览器帮助

支持

允许来源与访问诊断

工具栏“设”打开可信来源设置，无需重编译或重打包。每行填写完整HTTP/HTTPS来源，例如https://example.com或http://127.0.0.1:8765。协议、主机和端口精确匹配，不允许凭据、路径、查询、片段或通配符。空列表拒绝全部网络。

保存取消在途请求并返回包内首页；其他实例500ms内重读用户文件。非法编辑不覆盖旧规则；磁盘配置损坏时拒绝全部网络。点击默认或删除%LOCALAPPDATA%\ui-framework\browser\origins-v1.txt恢复包内规则。缺失文件才使用包内默认值。远程页面不能修改来源。

工具栏“诊”显示当前导航的分类、网络阶段、Windows/HTTP/TLS码、重定向来源关系及图片/CSS失败。主文档可读但资源失败会标为部分呈现。诊断隐藏凭据、路径、查询和表单内容，容量有限时明确标记省略。不要把放行来源当作整站兼容保证。

网络使用WinHTTP系统/用户自动代理，不修改系统代理、不自动认证、始终验证TLS证书。地址/协议/凭据/来源拒绝请修正对应项；网络失败可重试并核对网络/代理；TLS错误应核验证书；HTTP错误请检查服务器；文档或资源超限不提高预算绕过。

HTML 段落、标题、换行、粗体与斜体、链接、列表、基础矩形表格、pre/code、PNG/JPEG/GIF 第一帧/BMP，以及简单 GET 文本表单。

页面可以选择复制、查找定位、横纵滚动及缩放。工具栏跟随框架主题，网页保持作者颜色。地址与标题保留完整内容；地址框使用 Home/End 与左右滚动。

限制

远程脚本、内联事件、应用桥、非 HTTP/HTTPS 协议、凭据 URL、未配置来源、自动认证、Cookie、存储、上传、下载、POST、密码等复杂表单均被拒绝。

iframe、SVG、Canvas、音视频等用明确标记代替。CSS 使用 Light 支持的颜色和字体；文档流布局简化了定位、复杂样式、表格合并单元格和动画。宽表格与代码长行可横向访问。

资源门槛

主文档 256 KiB，DOM 最多 1024 节点、64 层；单文本 4095 UTF-8 字节。最多 40 个子资源，每份 CSS 64 KiB、样式规则共 256 条，每图压缩数据 2 MiB、解码数据小于 8 MiB、每边 4096 像素。累计传输 8 MiB、累计解码与框架图片预算 32 MiB。超限会明确失败。

安全范围

工具栏属于可信应用，网页使用无脚本和无本机桥的独立文档视图。本版没有浏览器级进程沙箱，仅用于受控来源；没有验证任意恶意网站安全性。

键盘

Alt+Left / Right 前后    Esc 停止或退出查找
Ctrl+Plus / Minus / 0 页面缩放
Tab / Shift+Tab 访问控件与链接
Home / End 横向首尾    Ctrl+Home / End 文档首尾

M2阅读兼容性（0.3.0）

有序列表支持起始、倒序及单项编号。表格支持64列内合并单元格及表头。基础CSS保留作者颜色、字体和空白；隐藏文本不进入查找复制。JPEG应用EXIF八方向；动画仍只取首帧，诊断会标记。

简单GET保留空值、重复字段及提交按钮，禁用字段不提交；POST、密码、上传、复杂控件和提交覆盖会明确拒绝。片段在资源完成后定位。不存在的片段有提示，正文仍可阅读。
