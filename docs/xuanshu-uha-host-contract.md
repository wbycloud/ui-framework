# UH-A正式宿主只读任务与交付合同

2026-11-03。状态：本轮实现前冻结。面向框架和宿主开发者，沿用P3、RP-A/B、C2/P4/P5和既有生命周期；不授予真实服务调用或人工验收。SDK0.10-dev/API10/标准10、ABI1/包1，旧布局/错误值/额度不变。

## 1. 盘点及决策

| 已有能力 | 实际缺口 | 本轮改动 | 验收 |
| --- | --- | --- | --- |
| 一个Service/主对话、read调用和SQLite | 历史sequence/projection JSON日常手填 | 当前分页历史逐项选择；资源、read描述及Schema字段勾选，默认全不选 | 实际请求解析、未选数据不存在 |
| get_run有context_preview及固定目标 | 固定指令/工具未展示，post_json成功非完整显示证明 | 独立只读预览接口，分块只读控件与宿主逐块比较，成功才绑定 | 丢块/截断/旧摘要/显示失败零确认零发送 |
| 用户配置及原生Key/后台确认 | ready与凭据状态易混，正式显式DB未隔离模型路径 | 显式UI_AI_DB_PATH派生.model.json；默认用户路径不改；分阶段状态/诊断 | 替身、隔离路径、诊断哨兵 |
| 折叠/任务/旧诊断 | 状态缺少中文语义和可靠取得方式 | 单独只读诊断复制、稳定输入/选择/文本；保留stub/edit/graph | Light、重建、控制/关闭回归 |

不创建第二目录、Service或执行器。能力选择只用公开统一目录describe的effect=read，字段来自其output_schema.properties，不自动选择星号。不增加P2注册来源。无目标默认只发当前输入与所选历史，空白名单。分页历史不自动发送全对话；选择保存于页面草稿，提案复制后不被新页/标签改变。

## 2. 预览接口与显示门

新增ui_ai_model_get_disclosure(service,run_id,char **json)，UI线程只读、返回复制JSON、ui_ai_release释放。JSON version=1，绑定run_id/binding_hash，含固定目标、scope及完整初始request（model/stream/max_output_tokens/instructions/input/tools/reasoning），复用生产构造器，不能签发授权或联网。只在持久化等待确认且context已准备时成功，否则PENDING/NOT_FOUND/既有错误；无新错误值或旧结构改动。锁内复制，未跨应用回调或I/O；外层方法/任务在途不释放。输出受原128KiB上下文及既有工具定义限制，分配失败保持不就绪。

宿主将完整JSON按UTF-8边界分为每块不超过3000字节的只读控件，避免Light原4096字节文本上限；完整文本均可滚动查看，无需手抄/手填。宿主保存本轮复制的预览，并逐块从Light presentation读回比较，校验摘要及当前run/config状态后才建立原确认绑定；页面消息不能宣称显示成功。任何块缺失/不一致、post失败、摘要/配置变化、视图重建或关闭立即禁止旧绑定。相同预览稳定刷新不重建控件或反复disable/enable打断捕获。允许离屏滚动部分，不把必须人已阅读作为自动可证明事实。最终目标/epoch/revision/catalog核对继续由生产am_accept承担；变化拒绝，不自动改绑/重试。

## 3. 线程、所有权与配置

UI只做有界目录/目标/投影，不读库/网络/凭据。数据库、网络和凭据I/O继续后台；原方法/回调/worker/待消费结果引用与关闭门不变。新增API复制服务自有的初始上下文而非后台可变网络请求，锁内生成无应用回调。宿主借用JSON立即解析/复制并释放；宿主草稿不成为授权。配置打开按实际显式DB路径派生.model.json，未设置DB则沿用户默认模型路径；不读取/复制RPCB固定ref、不迁移用户库或凭据。Key状态只展示真实诊断：未配置、保存中、错误、本地可读/服务端未验证，不能把ready写成Key有效。

## 4. 状态及诊断

收到不等于保存；输入仅accepted/existing保存确认后按对应client清空。区分排队、等待外发确认、确认已收/已保存、请求已保存、发送、流式、read工具、取消停滞、最终保存及远端未知。折叠和应用切换不清空任务，重启恢复记录不恢复授权。诊断仅复制Service/模型/get_run已有脱敏字段，无密码框/Key/认证头读取；独立按钮不提交任务、不确认、不网络。复制失败明确显示状态，不要求用户手抄JSON。

## 5. 验收和停止

离线测试：结构化实际选择与序列化request一致、固定指令/工具逐值一致、预览块实际读回、丢块/截断/旧hash/伪造确认拒绝；真实workspace双实例、实际read值/revision、旧epoch、非法字段/read越权；未确认零发送、同步/多工具/取消/存储失败/cleanup-only/重启封闭/真实DLL和REFUSE；公共C/C++头、静态嵌入、Light相关编译分支和ASAN。沿用原限额/超时，不降低断言。原充分且仍匹配证据可复用并说明。

交付新独立构建/原始JUnit/首败同期源码与匹配程序、源码和二进制清单。自审不是独立复审，离线不是实际服务或设备通过。集中人工保留真实来源、Windows分类限制、IME/DPI/视觉/辅助技术/长时，断电只专用方案。停止在匹配交付与人工验收入口准备，不启动正式验收或索取Key。


## 6. 实现后的组织细化与交付状态

初版规格冻结后在同一方向内落实：独立公共头ai_model_view.h；宿主内存草稿复制（非数据库持久化），原生剪贴板复制及失败码；资源与read目录分别分页、按目标kind过滤。完整预览为初始请求和固定范围的全部分块，不声称用户已逐字阅读；模型续轮仅能发送同范围结果，原Provider验证/预算不变。配置路径显式/默认分支在正式宿主统一处理，没有固定ref复制。新增API目标回调重入关闭和revision拒绝已在Native/Light/ASAN覆盖。初版与这些细化均无公共旧语义/DDL/来源/生命周期边界改变。

开发/离线验证完成，详[验收记录](validation/xuanshu-uha-validation.md)，下一步仅[集中人工入口](xuanshu-uha-manual-acceptance.md)，当前未执行；不等于独立复审或真实服务验证通过。

## 7. UH-A限定复审后的三项整改（2026-11-03）

原交付经限定独立复审存在投影失败旧确认及长历史重复投影两项阻断，原“准备进入人工”只是当时开发自审结论，不能视为独立通过。本轮另有历史任务诊断整改执行授权，先冻结[增量合同](xuanshu-uha-projection-closeout-contract.md)再实施；三项开发闭环与最终相称验证见[整改记录](validation/xuanshu-uha-closeout-validation.md)。当前停止再次限定独立复审前，不继承原快照验收或自行冻结。

独立限制性展示绑定在接纳前/最后目标回调后重查run/hash/展示代次及实际控件；状态投影失败即失效，解绑PENDING也不例外。2MiB有界宿主组装、8192字节UTF-8片及SHA256/顺序/代次，不提高Light256KiB或模型/arena额度；完整预览逐值读回，历史原全文路径保留并标注选择摘要。历史诊断使用内存优先/异步持久化快照、唯一查询ID加run ID，保留终态真实错误及来源。冻结P3/v1/C2/P4/P5、旧结构/错误值及普通逐任务可信人工来源不变。
