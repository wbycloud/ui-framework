## 源码因果约束

src/backends/light_text.inc:65的替换函数先计算UTF-16选区a/b与原长度len，再按前缀、插入、后缀组装，包括NUL。对合法选区0≤a≤b≤len、未被改写的完整ASCII输入offline-fixture，组装长度为a+15+len-b，必然不少于15。因此，在这些前提下，普通选区边界偏一不能直接生成14字节offline-fixtur；必须有不同输入、后续写入或不满足此前提的破坏。此为源码条件证明，不冒称原首败已经记录这些前提。

lw_wide按-1取得包含NUL的转换尺寸，替换缓冲转换也按-1处理。原失败归档与本轮入口light_text.inc的差异只有此前BR1写入追踪，见original-input-diff.patch；不能用另一版已修算法替代原始算法解释。

输入后的合法写入入口包括lw_dom_set的value赋值、lw_text_replace（整串、原生字符、剪贴板、IME及删除）、撤销/重做历史恢复、节点初始化/重建。host.html:274仅在模型框为空时填入配置值，非空值的普通状态刷新不执行这条赋值。页面保存读取value后复制到宿主动作；前轮排队/worker屏障已排除所测的DOM借用及action释放后借用假设，但未证明原失败经过哪个入口。

## 预先限定实验

experiment-plan.md先声明每配置每条件一次、原30秒门槛、Light后ASAN串行。七组最小矩阵不保存模型配置、不创建任务、不授权、不传输。矩阵后另行预先声明一次原persisted上下文关联，每配置一次，复用其两个stub种子历史和一个未确认任务。首次不一致立即停止后续输入并安全关闭，不重填、不删除末字符、不自动补字符。

六个边界为raw、converted、temporary、written、callback、layout。有界128记录，比较每次新增恰好六条记录、节点UID、实际全文及含NUL字节；缺失/超额记录均失败。回调后按UID重新找节点，不继续访问可能迁移的旧地址。已有消息观察器继续检查泵前后实际控件全文并锁存首差异。追踪和回调改变执行成本，不称无扰动或任意地址硬件监视。
