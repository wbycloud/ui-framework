## 2. 恢复集中验收的方法

1. 先获得明确集中人工验收授权，核对当时Git、源码、开发SDK和二进制；20261023/24包只代表本阶段，软件整体完成后若源码变化必须重建匹配包。
2. 沿[原清单](xuanshu-p2-manual-acceptance.md)的独立profile、OPEN实例ID、F6前后业务回读、固定目标、冲突、UNKNOWN及关闭步骤操作。使用当时有效的启动脚本，不覆盖冻结SDK或历史用户数据。
3. D01—D08逐项记录实际结果，保留未验项。Windows分类证明范围必须随记录同行，不能以HARDWARE标签证明物理来源。
4. 失败保留匹配二进制、源码身份、原始日志、实例/资源/open epoch/revision/call ID、操作顺序和最小必要截图/dump；保留首次失败，不用后续通过覆盖。

本轮不要求用户现在操作，不执行真实设备/SendInput动态矩阵，不授予P3、AI服务或其他产品范围。
