# 框架自有界面视觉规范

当前SDK0.9/API9/标准9、ABI1；本轮实例语言与文本更新按版本规则升级；列宽与help是此前API8能力，既有内部视觉和生命周期复用。当前证据见[体验验收](validation/component-experience-validation.md)，此前API7内部视觉证据见[历史记录](validation/visual-ui-validation.md)。

共同表格的表头和内容按稳定列ID对齐，不依赖数据源cell数组的返回顺序。调宽改变可见列范围时，顺序已正确的DOM节点保持挂载，避免真实Runtime指针捕获被重排打断。列宽与布局存储由[完整应用示例](../examples/stateful_components/README.md)演示，内部模板修正保持API8；[本轮真实错位、捕获失败与复验](validation/api8-stability-state-validation.md)保留原证据。

## 1. 覆盖清单与设计目标

| 界面 | 当前实现与责任 |
| --- | --- |
| 独立宿主 | 浏览器式标签标题栏、窗口控制、最近/标签分页、两行菜单工具、工作区外框、助手、日志/状态 |
| 共同模板 | 按钮/勾选、枚举、RGBA与透明度、字段/表单、树/列表/表格、排序/选择/编辑、完整范围滚动、图片状态、Web对话框与状态 |
| 菜单与浮动面板 | 框架轻量Web浮层、连续菜单行、侧向级联、Web浮动标题 |
| 原生嵌入 | 系统菜单/工具栏/确认框、原生面板标题及应用自有编辑控件，按Windows/应用可定制范围呈现 |
| 应用自有内容 | HTML、原生控件、业务图标和GL画面由应用管理，不强制注入主题 |

原界面存在蓝灰大色块、共同组件固定深色、输入与标题高度不一致、标签符号依赖字体、助手默认展示协议细节等问题。本轮使用中性表面、单一蓝色强调、紧凑行距和明确状态，保留原来的几何、输入和资源合同。

## 3. 角色与状态

菜单是紧凑平面文字入口，展开/悬停/聚焦高亮；工具为小尺寸图标/文字按钮；应用标签有活动表面、名称截断和独立关闭入口；窗口控制有各自命中与关闭红色状态。没有将所有button改成菜单样式。

面板标题与标签式停靠减少重复包框，分隔条悬停/拖动显示强调色，停靠预览沿用原native预览。浮动标题同步主题，不重建内容槽、组件或GL context。布局格式2读取1和稳定面板ID不变。

表单紧凑对齐标签、单位和值；空单位/错误不占额外行，长文本沿原裁剪/滚动访问，错误在字段边框和文字两处表达。枚举与颜色浮层使用相同表面；颜色显示文字按亮度选取黑/白，透明度和提交/取消语义不变。树/表格图片分别显示加载、失败或资源图；无数据与加载提示使用有界模板节点。

框架虚拟树/表格/列表的滚动条继续按完整total和列宽工作，BigInt处理uint64，不以当前缓存页替代数据范围。普通overflow区域在轻量后端由GDI绘制12像素条，在WebView2由浏览器滚动条样式呈现；两种机制不混淆。共同数据组件不再显示分页或列箭头按钮，回收操作栏高度，完整范围滚动可访问首末行列，预算未提高。菜单、最近及标签列表的分页不受影响。

## 4. 两后端与原生边界

轻量解析受控CSS子集，支持本轮祖先hover/pressed、焦点、box-sizing及指定字体；WebView2使用同一模板和公共语义，额外的webkit滚动条伪元素由浏览器处理，轻量不解析它。字体抗锯齿、选区和原生编辑细节不保证逐像素相同。

宿主箭头、加号、溢出、最小化/最大化/还原/关闭及Web浮动按钮使用Windows10及以上随系统提供的Segoe MDL2 Assets字体，轻量以GDI字体绘制，WebView2以CSS字体绘制，不附带图标库。[Microsoft字体与码位说明](https://learn.microsoft.com/en-us/windows/apps/design/iconography/segoe-ui-symbol-font)。字体缺失的精简Windows镜像须补齐系统字体，不能仅凭HTML加载成功断言图标正确。

独立宿主主题同步到所有打开实例的框架共同组件、菜单与Web浮动标题；嵌入共同模板默认浅色，本轮没有增加公共主题设置API。应用自有Web/原生/GL内容仍由应用管理；原生系统菜单、消息框、应用嵌入标题等保留Windows外观，未替换成共同TreeView/ListView或伪造统一截图。

## 5. 助手与生命周期

每次启动默认收起，只由右上AI手动切换；resize、变大或切换应用不自动弹出。收起完整回收工作区宽度，展开重算原生及GL内容尺寸，固定目标实例的规则不变。

普通视图优先显示目标、可读操作名称、至多8个受支持基本参数、执行/取消、状态与可读结果。枚举/嵌套等复杂schema转到明确的高级输入路径。高级区初始折叠，包含事务/快照、schema、原始JSON及完整日志，所有原高级操作仍可访问。普通输入更新现有参数JSON、保留未知字段；非法草稿保持并禁止执行旧有效JSON，合并参数按原4095 UTF-8字节上限检查，基本整数只接受safe integer。原JSON数值token不能无损往返（包括大整数或非规范指数/小数写法）时保留原字节并转到高级路径。权限、validator、确认、事务、取消和结果仍走同一C合同；不新增模型服务。

关闭继续REFUSE/WAIT、消息泵、异步cleanup和DLL卸载。没有改变节点1024、JS8MiB/50ms、图片/缓存/队列、日志32000字节与预览4095字节等门槛。[复验与实际限制](validation/visual-ui-validation.md)分别记录自动验证和物理/人工待验。

工具尺寸按标题Latin/CJK单位有界估算；纯图标紧凑入口40逻辑像素，文字项70–240，长标题保留提示与溢出访问。标题标签/图标对齐20逻辑像素，菜单宽度和项目/节点预算不变。

## 完整窗口密度与几何复验（2026-10-07）

空组件标题隐藏并回收空间。字段面板宽度至少220且短标签、非多行/图片/组时，80像素标签与值同行；窄窗、长标签及展开选择器堆叠。单位16像素行高，颜色文本和箭头共用一行。每字段增加一个有界值容器，仍按原节点预算验收。

表头和单元格均使用应用声明列宽的min/max约束，保持两后端横向几何一致；行32、表头28、图片24，STYLE预览按列内宽度保持比例。独立IMAGE字段读取现有C资源尺寸，按视口保持比例，不更改像素、所有权或GL输出。只读且没有编辑/提交/取消命令的表单隐藏无效操作栏，对话框仍可取消。

宿主图标显式padding0，标签名称内距10；同区停靠标签置于工具前、按有界页成员分配宽度；浮动工具20与标题28匹配。菜单子节点继承所属行悬停处理，不能依赖轻量mouseenter冒泡。原同HWND捕获与加载覆盖层保留，完整数据滚动条不按缓存页替代。[本轮前后截图、红例与最终回归](validation/visual-polish-validation.md)。

## API8 本轮体验增补

表头调宽区域6逻辑像素，交互宽24–4096；不自动改变应用列宽。勾选/色块/图片/样式列内距3，文本8，编辑边框与选择分开。长文本悬停/F1查看，128项枚举滚动/键盘选择，帮助与错误有独立层级。RGBA轨道根据实际字段宽度调整。浮动160×120、对话框240×180最小逻辑尺寸；停靠标签每页1–4项按可用宽度计算，长名称查看及重绘焦点恢复。公共能力与保存格式见[迁移](migration-v0.7-to-v0.8.md)，真实结果见[验收](validation/component-experience-validation.md)。

属性名称保留展示标签，不增加默认Tab停靠点。名称单击、文本右键或原控件F1打开组件内只读完整文本；输入框Ctrl+F1查看完整名称，选择器F1查看名称，选项F1查看完整选项。查看层可选择/复制并滚动，Esc或关闭按钮恢复原控件焦点；换源、失活或模态切换关闭失效快照。悬停提示不接收鼠标或键盘、不获得窗口焦点，关闭时不恢复历史焦点；模态提示从组件本地坐标按已初始化DPI换算，菜单和模态仍按各自焦点合同恢复。


## API9 中英文呈现

本轮新增实例语言及原位文本公开接口，列宽/help是此前API8能力。框架统一字典配合应用资源；文本改变不覆盖用户宽度或自动适配，长文使用既有截断/完整内容路径。浅深主题、角色样式、紧凑几何和预算保持；实际同尺寸完整应用截图见[API9验收](validation/instance-language-validation.md)。
