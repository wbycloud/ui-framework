# SDK 0.7 → 0.8：当前版本迁移

目标为SDK0.8.0-dev / API8 / 开发标准8，Windows x64/C11；应用ABI1、ui_app_query_v1、包格式1及既有枚举/字段偏移不变。新增公开列宽能力及可选字段帮助使API按版本规则升到8；其他视觉、工作区和输入修正没有独立升级ABI。只维护当前版本，历史加载分支的存在不构成旧包维护保证。

用同一交付的头文件、导入库、运行库和宿主重新构建；清单framework_api_version与DLL descriptor均声明8，其他包字段照旧。不要仅修改旧包清单，也不要混用SDK7头文件与SDK8库。原始业务数据、total_count及按first/count返回批次的合同不变，应用初始列宽无需为框架改写。

## 列宽与存储

应用注册的正列宽是初始逻辑像素，零仍表示120。框架不会自动适配或覆盖正初始值；用户手势和set_column_width允许24–4096逻辑像素，DPI改变只改变物理像素。表头右侧6像素是调宽区域，单击其余标题仍排序；拖动支持释放、Esc、捕获丢失、换源/排序、模态、失活和关闭取消。同步重算表头、内容、横向条及按需查询，保留稳定ID、选择和有效草稿。

表头右键或F10/Alt+Down打开“适配表头及已加载内容 / 重置本列 / 重置全部列”。调宽区域也支持方向键（8像素，Ctrl为1）和Enter/F10。适配是显式操作，只测量表头及现有预算内缓存文本/特殊控件，不扫描完整数据源；后续正常视口查询不代表全量适配。

components.h新增UI线程接口get_column_width、set_column_width、fit_column、reset_columns、save_columns、restore_columns（均以ui_component_为前缀）。只适用TABLE；非TABLE返回UNSUPPORTED，非法宽度/格式返回INVALID_ARGUMENT。状态文件由应用存储，不能写进框架模板或业务文档。注册稳定组件/列ID后、挂载前恢复，可避免中间视口查询；挂载后恢复同样有效。应用自行区分用户、文档及实例档案，框架实例间不共享宽度。

UCW1格式1是小端字节流：80字节头（magic、version、count、reserved各4字节，64字节NUL终止组件ID），每条40字节（33字节NUL终止列ID、3字节零保留、4字节宽度）。最多64条/2640字节，只保存相对注册初始值的改变。先以NULL询问bytes，再分配并保存；缓冲归调用方，恢复同步读取并复制结果，不保留地址。

恢复先验证完整长度、版本、保留位、UTF-8/终止填充、重复ID与宽度，全部合法后一次应用。未来版本返回UNSUPPORTED，异常输入保持现有状态；未知旧列忽略，新增/未保存列使用当前注册初始值。同组件ID是恢复前提，显示名或数组索引不作为身份；列定义变更在重新注册后按稳定ID匹配。换源与排序保留用户宽度。

## 属性及体验

ui_field_desc_t末尾追加可选help（x64偏移64、完整size72）；只有size覆盖整个字段才读取。用清零描述并填写sizeof，字符串由框架复制。字段帮助、单位、错误、枚举长项及F1完整文本使用共同模板；128项枚举在有界选择器中滚动，方向/Page/Home/End及Enter/Esc保留原草稿/命令合同。RGBA拖动只更新草稿，提交由原表单语义命令执行一次。

窄特殊列采用3像素内距；长文本悬停可预览，F1/文本右键进入组件内可滚动复制的完整查看、Esc恢复焦点；输入Ctrl+F1包含完整名称，展示标签不增加Tab停靠点；焦点、选择和编辑有独立表现。数据组件仍无分页按钮，完整uint64/BigInt范围条及缓存预算不变。浮动面板最小160×120逻辑像素，Web对话框最小240×180；长面板标题和停靠标签可悬停/F1查看，标签按可用宽度保留溢出访问。布局格式仍2，布局及GL context复用，不建立新分割树。
