# 正式只读助手简明操作说明

适用快照：[DH-1交付清单](xuanshu-readonly-delivery-manifest.md)。本文是操作说明，不授权立即开展有Key真实调用；本次文档收尾没有启动程序或读取凭据。

## 日常操作

1. 顶部“AI”展开助手。会话记录和任务列表用于选择当前查看任务；“当前任务与处理状态”和“当前任务结果（与新任务草稿分开）”显示该任务事实。狭窄空间可用任务列表折叠入口。
2. 在“新任务草稿”下的“任务输入（填写要本地保存的任务内容）”编辑新任务。查看历史任务不覆盖草稿，修改草稿不改变已接纳任务。页面内保留不等于进程重启后草稿持久化。
3. 展开“选择新任务范围 ▸”，选择需要的历史片段；默认不选历史。通过“选择当前应用的只读目标与能力”选择资源、允许的read能力和字段。未选历史、其他应用快照、业务文件及完整主对话不会自动加入。rpc_memory仅是合成验证夹具。
4. 点击“保存任务并查看范围”进行本地提案。收到不等于保存成功；等待“持久化接纳”事实。失败时保留草稿和选择，先查看错误，不重复点击追求通过或自动重试。
5. 用“查看本任务范围（只查看，不授权）”查看“本次允许发送的内容”“已接纳任务的固定目标”和任务绑定的模型/read白名单。这些属于已接纳任务；切标签或编辑新草稿不重新绑定该任务。
6. 展开“完整请求详情”，按序查看全部分块，包含实际固定instructions、tools、输入及所选历史；hash、epoch和JSON是详情，不需日常手填。摘要不能替代完整预览。
7. “确认此任务外发范围（一次）”属于独立逐任务可信人工授权，与本地保存不同。本文不授权点击或真实发送。普通任务不使用RPCB批次授权、固定凭据复用或自动批准。
8. 需要停止时点击“请求取消当前任务”，等待实际终态及最终保存。取消请求不等于已经cancelled，本地取消不等于远端停止或免除费用；远端未知应保留。
9. “复制脱敏诊断（不授权、不发送）”取得必要诊断，然后正常关闭窗口。复制不提交任务、不联网、不读取密码框；不要上传Key、Authorization、凭据Blob或完整内存。异常未收尾时保留现场，不强杀、不提前卸载、不清除UNKNOWN。

## 设置与开发诊断

“设置”按需展开模型配置与凭据状态，并显示当前配置位置。未配置、正在保存、保存失败、本地可读取、服务端未验证分别理解：配置ready不证明凭据可读，更不证明服务端认证成功。默认路径和隔离路径见交付清单；不自动迁移用户库或复制凭据。

“开发诊断”保留stub、受控编辑、图和命令诊断。stub任务是本地诊断，不能代替真实模型任务或扩大权限；日常用户无需填写stub脚本、资源ID或projection JSON。

## 如何判断状态

| 状态或操作 | 正确理解 |
|---|---|
| 收到 / 持久化接纳 | 前者是收到提案，后者才有保存确认依据 |
| 等待确认 / 排队 / 发送 / 流式输出 | 不同处理阶段，不能由预览出现推断已发送 |
| 工具结果 / 最终消息 / 终态保存 | 工具完成、回复与最终持久化是不同事实 |
| 请求取消 / cancelled / 最终保存 | 依实际状态分别判断；UNKNOWN和cleanup-only不代表可以恢复正常派发 |
| display_valid=true | 不能单独解释为获得外发资格 |

确认仍须满足完整详情、实际文本与布局、run/hash、展示代次和运行时条件，以及最后一次应用回调后的复检。范围或详情隐藏、投影失败、内容中断、配置/目标条件变化或重建时，旧资格失效；恢复后由宿主重新核对，页面自报成功或缓存命中不能授权。

遇到串任务、错误目标、意外发送、存储不明或关闭异常，停止相关操作，保留匹配程序身份、任务ID、脱敏诊断、对应截图与stdout/stderr。正常退出后再由获授权的只读核对检查自有库；有未合并WAL时不得忽略或擅自checkpoint。不要反复重启或重复提交。

## 范围边界

当前材料覆盖匹配快照的限定开发、复审及自动界面验收。合成输入不是实际设备来源正例；没有全程网络遥测的记录不等于抓包证明。真实业务应用、全部人工及真实服务不由本说明宣称通过。已取消的临时控件测试不再安排。
