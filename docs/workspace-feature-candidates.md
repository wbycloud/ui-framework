# 后续公共工作区能力候选

2026-10-09方案交付，仅整理范围、公共接口影响和验收，不实现。本轮缺陷结果及未定位项见[验收](validation/ui-repair-validation.md)。托管超时、历史持续重绘、泛化192叠层和窄表头残影仍需各自验证，不能用这些候选代替修复。

## 命令搜索面板

范围：搜索当前宿主注册的命令标题、路径和快捷键，展示实时可用/禁用/执行中状态；上下键选择、Enter执行、Esc关闭并恢复原焦点。语言切换原位更新标签，稳定命令ID和已有处理器/参数/作用域保留。空结果、失效命令、切换应用、正在关闭的拥有者都应有确定行为。默认快捷键候选需先检查冲突；不覆盖应用已有快捷键。

接口影响：优先复用命令注册、状态查询、快捷键和公共组件数据源。若框架提供统一入口，另行设计独立size描述的显示/隐藏接口、快捷键配置和可搜索范围；本文没有声明新的已实现接口。不扫描业务私有对象，不将每次输入解释为可执行命令。

验收：中英文/空查询/长标题/禁用项、键盘和真实鼠标、窄窗口及程序/物理DPI分开检查；打开关闭不丢草稿或焦点，Enter至多执行一次，命令撤销后不可继续执行。结果采用现有虚拟窗口和完整范围滚动；沿用当前注册数、节点、内存、事件及延迟门槛。先测当前上限的检索延迟与增量状态更新，再确定新增预算，不能先放宽现有门槛。

## 嵌套分割工作区

范围：水平/垂直组合、拖动分隔条、叶子内容槽、保存恢复和焦点保持；至少覆盖左右两栏、某一栏上下分割、极窄窗口。结构与内容身份分开，调整和恢复保留编辑草稿、HWND、Web视图及GL上下文。

接口影响：现有平面region/面板布局不足以表达任意树。拟议独立节点描述、稳定叶ID、树验证及原子应用入口；不扩写现有结构偏移或偷偷复用枚举。布局持久化需明确新格式版本、未知ID、缺失内容及损坏数据的回滚；不修改本轮UCW1或冻结SDK。先确定真实业务所需深度、叶数及最小尺寸，再决定节点/深度上限和版本升级。

验收：真实鼠标连续调整、Esc/捕获丢失回滚、极限大小与DPI、内容状态/焦点/上下文保持、保存后重启等价恢复、异常输入原子拒绝。布局期间监测请求次数、节点与内存，验证不随数据总量增长；显示反馈经过GL仍可辨。多屏和物理混合DPI单列环境验收。

## 冻结列、可变行高虚拟列表

目前缺少实际使用方对冻结列数、列宽总量、可变高度分布、数据规模和可接受更新延迟的量化需求，仍是候选，不能宣称已有资源预算或自动进入实施。

冻结列须明确按稳定列ID还是前N列指定、排序/隐藏/调宽关系、左右滚动边界与编辑/选择唯一性。可变行高须明确高度由数据源提供还是内容测量、估计高度何时校正、滚动锚点如何保持。公共查询批次和64位ID、数据generation、缓存预算及UCW1责任不变；若需新增字段，另设完整size描述及能力合同，确定对应开发版本。

进入实施前：取得以上真实需求；在现有节点、缓存、内存、请求及耗时门槛内测量固定行高基线与最差候选。禁止预请求整个大数据集的行高、重复创建编辑器或复制全量数据。验收包含大数据端点/拖动/滚轮/Home-End、行高异步变化与重排、冻结交界处真实可见性、稳定选择/草稿/焦点、窄窗口、两后端及实际GL共存。PERF-001保持原样；新增测量和提案使用独立证据目录。
