# 应用代操作任务增量合同

2026-11-25。实施前规格。前置候选为 `7a4b2e`，工作区已有修改和历史交付保留。

## 应用接口

应用在已有资源、read 和 P4 动作注册后，用独立的 `ui_ai_operation_register` 注册可选任务声明。声明归属实际 App 实例的同一能力目录。沿用资源、描述指纹、输入输出 Schema、可撤销风险、业务事务与回读。宿主和模型提示只解释通用结构。从目录选择 App 注册的业务名称，多个可行对象在本地澄清。

| 字段 | 含义 |
| --- | --- |
| `id`、`title`、`resource` | 应用内稳定目录标识、业务名称及既有资源 ID |
| `observe` | 已注册的 read 及允许披露的字段投影，输入沿用原能力 Schema |
| `actions` | 主动声明的可撤销 P4 动作、与回读对象相同的身份参数及动态参数允许引用的字段 |
| `max_actions` | 本根允许的最大修改数，最多 8 |

应用按资源提供可复用业务能力。每条用户任务的观察对象、目标和允许参数来自候选计划及当次确认。`observe.fields` 支持标量原值和数组计数，均须有实际输出 Schema。同一资源内允许固定多个观察对象，例如源格和目标格。后续动作参数可采用确认的具体值，或引用同一根最近一次核实观察的某个字段。动作的目标定位参数必须固定并与指定回读对象一致。字段引用须命中同一根固定的观察对象及应用声明的参数来源白名单。框架只复制该字段的原值并用原 Schema 校验，不求值脚本、不拼接命令。

完成条件由用户确认的一项实际观察字段与固定值或获准的观察字段精确比较。可选 `increase` 要求实际回读严格增大且不超目标。P4 回执必须证明已提交，并给出事务、撤销回执和新框架版本。独立业务读回必须处于同一新版本。P4 回读若同时返回某个批准字段，该字段也必须与独立读回一致。委托只接纳普通、可撤销的应用内存写入。破坏性、对外及不可撤销动作保留旧 P4/P5 的逐项审批和执行边界。

## 两次可信确认

打开聊天中的「代操作」，对当前业务对象本地建立任务。普通问答及读取仍走原入口。第一次确认核对任务原文和有限的结构化目标请求，模型可提议观察对象、动作参数的固定值或引用、完成判断，也可提出澄清问题。初始请求携带注册约束和能力 Schema，应用业务值尚未外发。

本地按参数读取实际对象。授权界面列出固定 App 和对象、完成条件、将披露的事实、可执行动作、固定参数及获准字段引用、当前版本和限额。第二次确认沿用可信 Light 输入、完整预览实际内容、run/hash、展示代次、绑定及末次回调检查。SQLite 持久确认之后才启动下一轮及发起动作。页面、应用描述及模型响应只提供数据。

每个后继模型轮次收到真实投影及当前版本，提议一个已列动作及具体参数，或提出问题。核对实际目录、描述指纹、参数来源和值、当前版本、P4 策略和预算后，将本步参数固定并使用原 Coordinator 和 P4 执行一笔事务。每笔具有由框架生成的唯一操作身份。确认时的实例、host/open epoch、观察对象和根目标固定。仅在已保存的 P4 提交回执及独立业务读回相符时接受新版本。确定目标已达成即结束。已满足目标时零新增动作。

所有模型轮次、观察和动作属于同一 Service 和根任务。复用原计量和费用账本，本根最多 8 个模型请求及 8 个写动作，自首次可信确认起最多 10 分钟，费用阈值最多 USD 0.10。占用不返还，不延长当前根。每个写入或观察包保留原 Coordinator 结构预留和计数，实际模型请求由根账本单独累计。保留既有模型、节点和 Service 预算、DDL、公开布局、SDK/API/ABI 版本，以及旧固定计划中逐步骤精确绑定的规则。

## 停止和恢复

参数越界、目标或版本变化、能力变化、无法核实进展、存储故障或费用未知均停止后继请求及派发。取消和手动接管立刻禁止新工作，已取得的写门和事务继续按 P4 规则排空和保存。已有模型传输仍由原 worker 收尾，待在途引用归还、传输结束保存后再提交根终态。应用回执不确定时保留业务 UNKNOWN。人工停止和远端传输或费用不确定可以同时成立。接管后的原根停止，重启只恢复记录。

## 直接验收

先对通用组件的真实单元格观察修前文本答复及业务值。修后分别验证固定值写入及同一句复制任务的两个不同源值。源值来自运行中的实际观察，初始模型调用只收到任务和注册约束。验证实际业务值、版本、P4 账本和持久化根任务。锁定通用宿主、生产及隔离 DLL、页面、通用配置和提示后，再接入 minimal_eda。它只增加自身 SDK 注册，使用不同初始图块数和已满足目标验证。受影响回归包括旧计划、精确授权、重复动作、外部变化、关闭接管及重启。全部网络和凭据使用隔离替身。
