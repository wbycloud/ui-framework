# 公共 FORM 与 DIALOG 布局

SDK0.9.0-dev/API9/标准9开发分支的增补。使用本轮同一commit的头文件、导入库与运行库；冻结API9 SDK不包含这些新增导出，不能仅凭API数字混用。现有描述结构、偏移、枚举、ABI1、包格式1、模态与数据合同保持原样；没有改写历史SDK或标准。新增独立的 `ui_dialog_layout_t`、`ui_field_layout_t`，以及三个C函数，均在UI线程调用。

## 对话框尺寸

`ui_component_set_dialog_layout`只接受DIALOG和完整size描述；验证失败不改变现有布局。`ui_component_get_dialog_layout`查询首选尺寸及约束，并解析零值默认。所有尺寸为96DPI逻辑客户区像素，不包含系统边框。

| 字段 | 零值与范围 |
|---|---|
| preferred_width | 默认440；正值为首选宽度 |
| preferred_height | 按字段、说明、单位及错误计算初始高度 |
| min_width/min_height | 默认240/180；正值为最小客户区约束，至少160/120 |
| max_width/max_height | 零表示监视器工作区；正值与工作区取交集 |

各数值0..32767（正值最小宽/高还须至少160/120），最大不能小于有效最小；首选尺寸夹在最小/最大之间。监视器空间不足时工作区优先。系统边框按窗口报告DPI计算；内容按框架设置DPI缩放，两者不可混称物理高DPI。首次显示按内容定位/计算尺寸；后续内容更新、关闭再打开保留已有用户尺寸、草稿与视图。显式再次设置布局会重新应用首选尺寸。分组说明和错误保持独立焦点及完整内容入口，字段过多时外层容器滚动，按钮固定在顶部。Light的长说明同时统计文字自身换行高度并按独立滚动偏移绘制；真实滚轮可到达说明末尾，不能以外层字段已可见代替。

## 多行字段

`ui_component_set_field_layout`接受FORM/DIALOG注册的多行TEXT字段。id仅在调用期间读取；配置按注册字段保存。height优先于visible_rows：行数0..100，显式height为42..32767；零/零恢复四行默认。42为一行文字、内边距和水平滚动条留出必要空间，不能声称28像素下仍完整可读。默认98；行数N按19像素行距加22像素滚动/边距预算计算，单行最低42。不同后端实际字体行高可能不同，行数表示首选可视容量；显式高度和实际可读性应分别检查。

换行支持LF/CRLF。只读只禁止修改，仍保留焦点、选择、复制、内部横纵滚动和完整内容入口。内层字段滚动负责字段内长内容；外层容器滚动负责到达后续字段。更新不重新创建视图；旧提示关闭，避免显示旧文本。

## 示例与键盘

[可运行C示例](../examples/dialog_layout/main.c)通过 `dialog_layout_example` 构建；程序打开两字段公共对话框，notes首选六行，Enter提交成功后关闭，拥有者Enter再次打开。普通多行字段Enter插入换行，Ctrl+Enter提交；Tab/Shift+Tab在可操作项间移动，Esc取消；只读字段仍可导航。外层滚动不影响按钮可发现性，关闭恢复原拥有者启用及有效焦点。

[自动回归](../tests/component_layout.c)覆盖Light和实际Runtime、96/144/192程序DPI、单/多字段、错误/长说明/窄窗口、完整size、无效约束原子拒绝及关闭再打开。[真实输入复现](../tests/interaction_probe.c)另行验证41行末行、内外滚动和键盘；[显示调查](../tests/display_probe.c)保存真正可见尾部和原始失败。结果与限制见[本轮验收](validation/ui-repair-validation.md)。
